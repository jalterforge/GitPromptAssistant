GitPromptAssistant

Turn GitHub Issues into AI-ready Markdown in one click.

GitPromptAssistant は、GitHub Issue を AI が解析しやすい Markdown へ変換し、 ワンクリックでクリップボードへコピーできる Chrome 拡張です。

主な機能

  • GitHub Issue を Markdown に変換
  • 見出し・箇条書き・番号付きリストを保持
  • テーブルを保持
  • コードブロックを保持
  • AI向けプロンプトを生成
  • ワンクリックでクリップボードへコピー

対応AI

  • ChatGPT
  • Claude
  • Gemini
  • GitHub Copilot Chat

使い方

  1. GitHub Issue を開く
  2. Copy for AI ボタンをクリック
  3. AIチャットへ貼り付ける
  4. 解析・レビュー・要約を依頼する

プライバシー

GitPromptAssistant は、ユーザーの個人情報を収集しません。 処理はブラウザ内で完結し、外部サーバーへデータを送信しません。
