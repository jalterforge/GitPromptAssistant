GitPromptAssistantについて

GitPromptAssistant は、GitHub Issue を AI が解析しやすい Markdown 形式へ変換し、 ワンクリックでクリップボードへコピーする Chrome 拡張機能です。

収集する情報

GitPromptAssistant は、ユーザーの個人情報を収集、保存、送信しません。

拡張機能は GitHub Issue ページ上の情報をブラウザ内で一時的に処理し、 Markdown へ変換してクリップボードへコピーするためだけに利用します。

データの送信

GitHub Issue の内容やその他の情報が外部サーバーへ送信されることはありません。

すべての処理はユーザーのブラウザ内で完結します。

第三者への提供

GitPromptAssistant は、ユーザーデータを第三者へ販売、共有、提供することはありません。

利用する権限について

本拡張機能は、GitHub Issue ページへ「Copy for AI」ボタンを追加し、 Issue の内容を Markdown へ変換するために GitHub ページへのアクセス権限を使用します。

これらの権限は、本拡張機能の機能を提供する目的以外には使用されません。

プライバシーポリシーの変更

本ポリシーは、機能追加や法令変更などに応じて更新される場合があります。

お問い合わせ

ご質問やお問い合わせは、 Chrome Web Store または GitHub リポジトリに記載の連絡先よりお願いいたします。
